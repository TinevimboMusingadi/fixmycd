# FixMyDistrict PWA Installation Guide

FixMyDistrict is a **Progressive Web App (PWA)** — install it on your phone or desktop for quick access and offline support.

---

## What is a PWA?

A Progressive Web App:
- ✅ **Installs on your home screen** like a native app
- ✅ **Works offline** after first visit
- ✅ **Loads fast** with cached assets
- ✅ **No app store** required

---

## Install on iPhone (iOS)

1. Open **Safari** (must be Safari)
2. Go to **https://fixmycd.vercel.app**
3. Tap the **Share** button
4. Scroll and tap **"Add to Home Screen"**
5. Name it **FixMyDistrict** and tap **Add**

---

## Install on Android

1. Open **Chrome**
2. Go to **https://fixmycd.vercel.app**
3. Tap the **three-dot menu**
4. Tap **"Install app"**
5. Confirm by tapping **Install**

---

## Install on Desktop (Chrome / Edge)

1. Open **Chrome** or **Edge**
2. Go to **https://fixmycd.vercel.app**
3. Look for the **Install** icon in the address bar
4. Click **Install**

---

## Troubleshooting

- **iOS:** You must use Safari
- **Android:** Try Chrome
- **Desktop:** Use Chrome or Edge
- **Offline doesn't work:** Visit online first to cache assets
